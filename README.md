## 🇬🇧 English

### About

Discipline Tracker is a full-stack productivity application that helps you build consistent habits through daily task tracking, time management, and progress visualization. The app features cloud synchronization, detailed statistics, and a visual calendar to keep you accountable.

### Features

- ✅ **Task Management** — Create, edit, complete tasks with built-in timers
- 📊 **Statistics Dashboard** — Weekly analytics, completion rates, time breakdown
- 📅 **Visual Calendar** — Color-coded days (🔴 red / 🟡 yellow / 🟢 green) based on task completion
- 🔥 **Streak Counter** — Track consecutive productive days
- 💾 **Cloud Sync** — MongoDB Atlas storage with JWT authentication
- 🌓 **Dark/Light Theme** — Toggle between themes
- 📱 **Responsive Design** — Works on desktop, tablet, mobile
- 📝 **Daily Notes** — Record reflections for each day
- 📤 **Export/Import** — Backup and restore your data

### Tech Stack

**Frontend:**
- Vanilla JavaScript (ES6+)
- HTML5 / CSS3
- LocalStorage + Cloud Sync

**Backend:**
- Node.js + Express.js
- MongoDB Atlas
- JWT Authentication
- bcrypt (password hashing)
- CORS enabled

**Deployment:**
- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas (cloud)

### What I Built

I developed the entire application from scratch:

✅ **Backend Architecture**
- RESTful API with Express.js
- MongoDB schema design (Users, History)
- JWT authentication system (register, login, token validation)
- Password hashing with bcrypt
- CRUD operations for tasks and history
- Data synchronization endpoints

✅ **Frontend Logic**
- Task management system (add, edit, delete, complete)
- Real-time task timers with pause/resume
- Calendar renderer with date navigation
- Statistics calculator (weekly totals, averages, best day)
- Filter system (all/active/completed tasks)
- Theme switcher
- Export/Import functionality
- Cloud sync integration

✅ **Deployment & Infrastructure**
- Production deployment on Render (backend) and Vercel (frontend)
- Environment configuration
- CORS setup for cross-origin requests

**Note:** CSS styling was generated with AI assistance. All application logic, backend, and frontend functionality were written by me.

## 🚀 Local Setup

### Prerequisites
- Node.js (v14+)
- MongoDB Atlas account (or local MongoDB)

### Backend
```bash
cd back
npm install
node index.js
```
Server runs on `http://localhost:7777`

### Frontend
Open `front/index.html` in browser or use a local server:
```bash
cd front
npx serve
```

### Environment Variables (Backend)
Create `.env` file in `back/` directory:
```
MONGO_URI=your_mongodb_atlas_uri
JWT_SECRET=your_jwt_secret
PORT=7777
```
